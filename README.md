季度复核只发了通知，超期没人确认的权限一直留着，复核报告却显示全部完成：这个仓库提供一个访问权限复核引擎，把权限、复核人、结论与结算放进同一个批次里管理。每个权限都要分配给明确的复核人，批次要有截止时间，超期未确认的权限默认撤销，复核结论必须留痕，同一权限不得被重复复核，批量处理时各批次互不影响。

## 契约

- 每个权限必须分配给明确的复核人。
- 超期未确认的权限必须默认撤销。
- 复核结论必须留痕。
- 同一权限不得被重复复核。
- 批次必须有截止时间。
- 批量复核时各批次独立。

## 不变量

- 超期权限一律撤销。
- 已确认与已撤销集合互斥，并且覆盖全部权限。
